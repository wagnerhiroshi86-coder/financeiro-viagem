# Financeiro da Viagem

Controle de gastos de viagem em duas moedas, offline, para celular (PWA).

- Funciona sem internet depois da primeira abertura (instale pela opção "Adicionar à tela inicial" / "Instalar app" do Chrome).
- Os dados ficam só no aparelho; entram por um arquivo da viagem (.json) ou criando uma viagem nova.
- Sincronização entre celulares por QR Code, sem internet.

Este repositório contém só o aplicativo. Nenhum dado de viagem é publicado aqui.

Bibliotecas de terceiros: ver `lib/LICENCAS.txt`.
